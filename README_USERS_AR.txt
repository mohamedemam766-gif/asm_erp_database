AMS ERP - نسخة إدارة المستخدمين والصلاحيات

التشغيل:
1) فك الضغط.
2) افتح start.bat.
3) افتح http://localhost:3000

الجديد:
- اختيار المستخدم من صفحة الدخول.
- صفحة المستخدمون والصلاحيات داخل النظام للـ Admin.
- إضافة مستخدم جديد.
- تعديل كلمة مرور أي مستخدم.
- تغيير صلاحية المستخدم: Admin / Accountant / Viewer.
- تغيير كلمة مرور المستخدم الحالي.
- حذف المستخدمين ما عدا admin.
- كل تعديل يظهر في Audit Log.
