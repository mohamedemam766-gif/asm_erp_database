# AMS ERP ULTRA FINAL - VAT + القيود + الصلاحيات + الترقيم

## التشغيل
1. فك الضغط.
2. افتح `start.bat`.
3. افتح المتصفح على: http://localhost:3000

## الدخول
- admin / 1234
- accountant / 1234
- viewer / 1234

## الإضافات الجديدة
- VAT تلقائي حسب النسبة المحددة في الإعدادات.
- تقرير VAT بالفترة مع طباعة PDF وتصدير Excel.
- إعدادات ربط القيود التلقائية بالحسابات.
- ترقيم مستندات احترافي حسب النوع + السنة + الشهر + مسلسل.
- صلاحيات تفصيلية للأدوار: إضافة، تعديل، حذف، اعتماد، ترحيل، إلغاء، إقفال، فتح، استيراد، تصدير، إعدادات، مرفقات.
- استمرار Workflow: مسودة → معتمد → مرحل.
- Audit Log وإقفال شهري ومرفقات وتصدير Backup.
- بيانات الموردين وأرصدة أول المدة محفوظة داخل database.json.

## ملاحظات
- صفحة إعدادات القيود والصلاحيات تظهر للـ Admin فقط.
- يمكن تعديل Prefix الترقيم مثل PUR / RET / PAY من صفحة الإعدادات.
- فاتورة المورد الخارجية تكتب في خانة رقم فاتورة المورد، ورقم النظام يتولد تلقائيًا.
